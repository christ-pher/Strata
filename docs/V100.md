# V100 / Volta local setup

This checkout accepts compute capability 7.0 and builds with CUDA 12.x. CUDA 13
cannot compile Volta code. The installer selects CUDA 12 even if CUDA 13 is also
installed. Pre-Ampere BF16 prompt projections expand BF16 exactly to FP32 and
use tiled SGEMM, with a SIMT fallback for narrow products. This ports the work
from [PR #130](https://github.com/Niko1221/Strata/pull/130) and
[PR #139](https://github.com/Niko1221/Strata/pull/139) onto the newer Turing-capable
source; the old `STRATA_EXPERIMENTAL_SM75` flag is no longer needed.

On this machine, the GPU reports Tesla PG500-216, sm70, 32 GB VRAM. The VM has
94 GiB RAM and exposes no AVX2. Native expert dispatch now uses scalar CPU
kernels when SIMD is unavailable; AVX2 tables are initialized only after dispatch.
CPU misses will be slower than with AVX2 exposed by the hypervisor.

Start the prepared IQ2_XS model and local web/API server:

```sh
cd /opt/engines/Strata
./run-v100.sh
```

The launcher binds to `0.0.0.0` without authentication, as authorized for this LAN.
From another LAN device, open http://10.0.20.99:8080. The OpenAI-compatible
API base URL is http://10.0.20.99:8080/v1. The launcher defaults to a 32K context, INT8 KV,
text input, and routed-only prompt staging (`STRATA_PREFILL_RING=8`).

Other sizes use the same engine. Their first run downloads and prepares the
additional weights; later runs reuse them. The original model's second shard
and MTP assets are shared:

```sh
./run-v100.sh Q2_0
./run-v100.sh IQ3_XXS
./run-v100.sh IQ3_S
./run-v100.sh coder
```

All sizes fit this machine's RAM. Additional sizes need more disk space. The
launcher keeps model weights in `/opt/models/Strata/models/`, packs and MTP in
`/opt/models/Strata/runtime/`, and its settings in `/opt/models/Strata/runtime/user-config/`.

Override setup options by appending them, for example:

```sh
./run-v100.sh IQ2_XS --context 65536
./run-v100.sh IQ3_S --no-start
```

Build manually with the pinned ggml dependency:

```sh
cmake -S . -B build -G Ninja -DSTRATA_ENABLE_CUDA=ON \
  -DCMAKE_CUDA_ARCHITECTURES=70 \
  -DCMAKE_CUDA_COMPILER=/usr/local/cuda-12.8/bin/nvcc \
  -DSTRATA_BUILD_TESTS=OFF
cmake --build build --target strata -j 6
```

Numerical regression targets are `bf16_gemm_test` and `scalar_experts_test`.
The BF16 test covers narrow products, both tile boundaries, beta accumulation,
padded output strides, and values outside FP16 range against CPU double sums.
GPU validation also uses the existing QSA, BF16 GEMV, GR, INT8 KV and Q4 KV parity
tests. End-to-end validation is recorded in `docs/V100-validation.md`.

## External model storage

The V100 launchers default to `/opt/models/Strata`: original downloads are in
`models/`, and prepared packs, MTP assets and local settings are in
`runtime/`. Override the root with `STRATA_MODEL_HOME=/path/to/models/Strata`.
The repository's old `data/models-download` and `data/runtime` paths are ignored
compatibility symlinks. Small upstream profiles and vocabularies remain tracked
in `data/`. Model weights and generated runtime files are excluded from Git.
